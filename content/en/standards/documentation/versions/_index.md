This history collects the 2020 workshop outputs, released review drafts, and, when available, adopted editions of OMF’s documentation standard. Each entry retains its text, any supporting files, and a provenance record with file checksums. Workshop material and review drafts are not adopted standards.

For the current proposal or standard, visit the [documentation page]({{< relref "/standards/documentation" >}}).

The announcement date records when review began; the capture date records when the linked files were saved here. Original downloads are preserved unchanged. The HTML presentation may evolve with the website’s design.
