# Security Policy

## Supported Versions

This repository hosts a GitHub Pages Hugo site. We actively maintain the current default branch and its published content.

## Reporting a Vulnerability

If you believe you have found a security issue in this site or repository, please report it privately to the maintainers at `support@openmodelingfoundation.org`.

Please include:
- A clear description of the issue
- The affected page or file
- Steps to reproduce
- Any relevant screenshots or proof of concept

## What to Expect

We will review reports as soon as practical and respond with next steps. Please do not publicly disclose the issue until it has been reviewed and resolved.
